03 / State belongs somewhere

A cache is not a database.

The app has several kinds of memory. Choosing the right owner explains most of the architecture.

WhatWhere it livesWhat that means
Unsent notes, journal text & quiz picksScoped SQLite drafts + React stateDrafts survive restart for their account/space/editor. Server acknowledgement clears only the accepted revision; this is not an offline delivery queue.
Shared notes & quiz answersPostgres, through APIBoth devices read the authoritative data. Neither phone decides what the partner submitted.
Previously fetched dataTanStack Query → SQLiteOwned, successful reads can reappear offline. This is not a reliable offline send queue.
Session credentialsSecureStore adapterKeychain/Keystore protects credentials. That does not imply all cached content is encrypted.
Photo bytesLocal disk / private object bucketPostgres holds metadata and keys; the app reads images with signed URLs.
Theme & touch preferencesDevice key/value storageYour partner can choose different colors. The shared content stays the same.

04 / The native boundary

Metro isn't your backend.
A bundle isn't a signed app.

How do I debug a failed note or quiz save?

Start at the mutation's error and HTTP status in the feature hook. Then follow lib/api.ts → Hono route → service → repository. A 401 suggests session failure; a 404 can intentionally conceal an unauthorized space; a 409 often means stale state or a conflicting operation. Inspect IDs/status locally, never private answer or note bodies in logs.

Why split QuizPlay from QuizPlayContent?

QuizPlay wires real query mutations. QuizPlayContent renders the flow and accepts save/complete callbacks. The development playground supplies local callbacks, so we inspect the real controls without fake authentication or writes to live data. QuizReveal / QuizReport use the same separation for results.

What makes the result the same on both phones?

The API locks the session while completing it, marks each participant finished, and sets readyAt only once both are done. Before that, partner answers are omitted. The API computes the shared report through scoreQuiz. Agreement and headline stay the same; personal prediction counts swap with the viewer. Historical content/scoring snapshots are a separate planned reliability improvement.

What is verified, and what still needs a device?

Typecheck proves static contracts, pure tests prove rules, and API tests prove HTTP/database cases. Native screenshots prove the layouts they show. Real push, widgets, background/offline behavior, screen readers, gestures and frame timing need device checks. This guide does not imply those integrations passed.

Where do environment variables and secrets go?

EXPO_PUBLIC_API_URL is public app configuration bundled at build time. Database/auth/storage secrets belong only on the API. Commit sanitized examples and migrations; keep actual env files, signing credentials, local media, generated native projects and review recordings out of Git. See GIT-HYGIENE.md.
