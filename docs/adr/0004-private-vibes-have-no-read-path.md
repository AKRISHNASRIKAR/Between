# Private vibes have no read path to the partner

A Vibe is private by default, and a private Vibe is indistinguishable from no Vibe: there is no query, event, notification, pet reaction or observation that can reveal it to the Partner. Sharing is an explicit act that can be undone. This is stricter than hiding it in the UI because check-ins only work if people trust they won't be surveilled.
